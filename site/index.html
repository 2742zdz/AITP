Your system

Paste into Terminal.

Enter the Gateway base URL to see the command.

Afterwards

Run Claude Code as usual; it now goes through the local proxy:

claude

Codex goes through the proxy with:

aitp codex

Start the proxy later with:

aitp --environment claude start

Uninstall

Removes the services, settings, data and the program AITP installed:

aitp uninstall
